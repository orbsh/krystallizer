# ADR-0029: 身份自成一册；合并永不改写事实

**状态**：草稿（2026-11-12）。承接 ADR-0028 关于权重如何随时间变化的讨论；这一条谈的是新知识到来时"一条事实是什么"。

## 背景

每次写入都会问同一个问题：这是我们已有的那个东西，还是新的？两个方向答错都会累积放大。太容易答"同一个"，不同的事实被压成一条，无法还原；太容易答"新的"，库里堆满近重复，热度被摊薄，而以后的合并又很贵——因为那时的合并意味着改写事实。

已有方案是粗筛带 id：取候选节点、交给 LLM，让它选既有节点或新建。这个形状对**模糊地带**是对的，对**常见情况**是错的：如果每次写入都要问，成本没有上界，而且答案会随模型、随日子漂移。

## 决定

**1 事实不可变，身份自成一册。** 一条事实是 `(subject_id, relation, object_id)` 加 payload，只追加、永不改写。"这两个实体是同一个"记成一条别名边 `surface_form --alias_of--> canonical_id`，而不是编辑任何事实。于是合并的代价是一次追加，且可逆；判错只是废掉一条别名，没有事实被损坏。

**2 三层判定，LLM 只出现在中间那层。**

```text
第 1 层  键碰撞：(canonical_subject, relation, canonical_object) 完全相等
         → 静默合并：计数前进、环右移，不做判断
第 2 层  同 (subject, relation)、不同 object、且高相似
         → LLM 判：同义（加别名）还是不同事实
第 3 层  其余
         → 新事实，不判断
```

  第 1 层必须吃掉写入的绝大多数，而这只有在前置归一把候选从原始字符串变成 **canonical id** 之后才成立——粗筛的职责是归一，不是挑选。

**3 粒度：一条边一个断言，配两条检验。** 一条事实是思维导图上一支箭的大小：节点是概念（你愿意画框的名词），边是断言（你愿意画箭的动词或介词），修饰是边上的字段——**永远不为修饰语造节点**。两条都成立才是合适的粒度：

- **能否单独被推翻**：能想象这支箭是假的、而旁边的箭仍然成立；
- **是否会被单独查询**：某个问题会单独指向它。

  第一条不成立 → 那是一段话，必须拆。第一条成立、第二条不成立 → 它是属性，放进 payload。

**4 谓词词表闭合且小。** 几十个关系（`is_a`、`part_of`、`causes`、`requires`、`contradicts`、`prefers`、`said_by`、`observed_at`、`supersedes` 之类），不是开放集合。语义上新的细微差别用**既有谓词 + payload**表达；为每次观察造一个谓词，正是让细粒度库变得不可查询的原因——每支箭的动词只出现一次，什么都组合不起来。表面形式的变化由别名层吸收，不靠新关系。

## 后果

- 冗余检查是局部的：一次写入的候选就是同一个 `(subject, relation)` 桶里的事实，前缀扫描即可。没有全局去重作业，也不需要。
- 合并实体便宜到"可以偶尔判错"，这正是要点：别名层就是系统被允许不确定的地方。
- 接受两项代价：近重复可能并存，直到第 2 层捕获；一条再没人看的别名会一直是错的。两者都在数据里看得见，而一次改写会把原始记录丢掉。
- 三个数说明粒度是否失调：每个 `(subject, relation)` 桶里的事实数分布（桶过大：粒度太细或谓词太泛；桶恒为一：太粗或实体没归一）、写入时选既有节点而非新建的比例、别名边的数量与增长。

## 被否

- **每次写入都问 LLM。** 成本无上界、答案不稳定，而且把合并决定放在一个无法再审视的位置。
- **全局去重作业。** 离线、昂贵，而且它判定的是事实而不是身份，所以产出只能是改写。
- **靠改写事实来合并。** 抹掉"曾经相信什么"的记录，而 ADR-0028 整套随时间变化的方案都依赖那份记录还在。
- **开放的谓词词表。** 写的时候方便，查的时候无用：组合的前提是同一个关系被反复使用。
