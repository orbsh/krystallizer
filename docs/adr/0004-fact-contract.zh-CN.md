# ADR-0004: 事实契约 — 核心零 LLM 依赖，编排归调用方

**状态**：Accepted。层级归属归 [ADR-0007](0007-consumption-boundary.zh-CN.md)
（没有 Python 层；LLM 编排归调用方——聊天消费方是 gravity）。留在本文档的：
确定性的 `ingest(fact)` 事实契约与融合拆分。
**日期**：2026-09-08
**英文版**：[0004-fact-contract.md](0004-fact-contract.md)

## 背景

graph-memory 设计里的两阶段提取管线（规范化 → 分类提取，每阶段一次 LLM
调用）作为机制退役：事实不是被另一趟单独提取出来的。**模型主动添加记忆，
在轮内**——记忆工具就是生产者，那次调用怎么接是调用方的事
（ADR-0007/0008）。剩下的是本文档回答的边界问题：LLM 编排住在 Rust 核心
里，还是调用方那一侧？写入时融合流程（域外实体收敛）同样涉及对小候选集的
一次 LLM 决策。

## 决策

**mem-core 接收结构化事实（定长 8 元组）；它永不调用 LLM。**

- LLM 决策——入图判据（针对性 × 概括性）、域外融合判断、策略需要时的摘要、
  一切 prompt 工程——住在**调用方**那一侧（ADR-0007：聊天消费方是 gravity；
  记忆主导的程序自己跑单遍推理），永不在核心里。
- 核心的入库面是确定性的：`ingest(fact)`，其中 `fact` 已是定长 8 元组——
  head 值 / head 类型 / head 属性、rel 名字 / rel 属性、tail 值 / tail 类型 /
  tail 属性（位置 0–7）。head / tail 带名字**和**类型标签；关系只带名字与
  属性——它的名字就是它的种类（**图自己的谓词字典**把它分配成 `predicate_id`，
  固定面 0x04/0x05，okm ADR-0017 §3），再加一层更粗的标签只会多一个没人读的面。空属性写 `{}`
  ——定长，槽位不省略——`category` 不属于事实的形态。类型词表归调用方且开放，
  只保留一个词项：`literal`（没有自身节点身份的值——日期、数字、短字符串）落成
  字面量节点。这个形态写在三处：
  wiki 的权威序列化节（krystallizer 双语）、knowledge-triplets skill 的格式节、
  本仓的 PROMPTS 双语对；读取就是普通的 `serde_json`（已是工作区依赖）。
- **融合在核心内按此拆分：**
  - **域内实体**（组织成员、项目、任务、商品）：稳定 id 确定性直查——
    零 embedding、零搜索、零 LLM。调用方的稳定 id 以属性 + 派生条目的形式
    到达图（精确入口），永不作为键材料。
  - **域外实体**：核心提供便宜的一半——embedding 检索返回候选事实
    **及其锚定的实体节点**——调用方跑昂贵的一半（模型判断：复用节点 /
    合并去重 / 新建节点），再带着决策调 `ingest`/`link`。
- **入图判据。** 能被「代码化」的记忆才值得拿节点：有规范名，且至少有一条
  可类型化的关系。理由是一条论据而非偏好——代码域是图检索被证明有效的地方，
  而代码白送的恰好是这两样：(a) 每个东西一个规范身份，(b) 有类型、有方向的
  关系（wiki graph-memory「为什么图有效：代码域的存在证明」）。两样都没有的
  记忆（闲聊、无锚点的印象）进图只会稀释权重：没有身份可供链接，关系也无从
  类型化。它唯一有的东西——语义相似——是入口层的事，不是图的事。

## 理由

- 核心保持确定性，不需要 mock 或录制的 LLM fixture 即可完整测试。存储层的
  每一条性质都能精确断言。
- LLM 编排是快变关注点（模型、prompt、成本策略每周在变）；存储 schema 是
  慢变关注点。分离让两者各按各的速度演进。
- 调用方本来就拥有 agent 集成（工具注入、提示词撰写、checkpoint 策略）。
  生产事实是同类工作。

## 后果

- mem-core 零 LLM 依赖，且完全没有网络面——embedding 模型内置（ADR-0003），
  入库是本地的，embedding 也是。
- 编排面归调用方：事实的生产、融合决策、触发策略。聊天消费方经 gravity 走
  （ADR-0007）；记忆主导的程序不需要 agent 中间层。
- **图的成本条件是建构**：身份（规范名 + 别名条目）与关系类型化是成本所在，
  跳过它们的入库只会产出孤立节点，而不会变成"检索差一点"。这条 gate 限制的
  是「什么能拿到节点」，从不限制「什么可以被存储」——原始内容的家在 channel
  日志（ADR-0008：每条消息、只追加），这条 gate 管的是从它建构出的长期记忆。
  入图判断本身归调用方（它是一条判据，与 specificity × generality 同类）。
- 第二种消费形态（记忆主导的程序）不需要重做任何东西：它调同样的 HTTP 门，
  自己跑单遍推理（ADR-0007）。
- 事实这条路上不需要 KDL 解析器；配置文件仍是 KDL（ADR-0007）。
