# 0017 — 尾操作是一张表，压缩一次答两份

> **语言：** [English](0017-tail-operations.md)（主） · [中文](0017-tail-operations.zh-CN.md)

**状态：** Accepted（2026-10-26）——第一阶段同日落地：`tails` 表、要两份产物的
提示词、checkpoint 行上的 `suggested_*` 字段，以及 gravity 侧读取两份产物的分支轮。
第二阶段（回顾分析）**未建**；给它的接缝在。
**日期：** 2026-10-26

## 背景

ADR-0008 §4 接了一个尾操作：压缩判词触发时，投影带上
`compress: { checkpoint, prompt }`，调用方把这段提示词接在那段记录后面，分支轮的
答案就是摘要。它写成一个字段，因为只有一个操作。

有两件事逼出了这份记录。

**操作是一类。** 压缩不是唯一值得对一整段做的事：回顾分析（「这一轮留下了该存的
技能或记忆吗？」）属于同一族——同样的时机、同样的形态（接在一次投影读取之后的
提示词，作为分支跑），产物不同。一个操作一个字段，等于每加一个都要改线上形状。

**压缩看得见预算看不见的东西。** 那段是字节预算加空闲时钟挑的，所以可能断在一轮
对话中间。压缩是唯一读完整段的人，读完之后模型看得出对话真正断在哪。这个判断值得
留下：给切分器当标签，也给下一个读这段的人当范围。

## 裁决

**1. 操作是一张表，不是一堆字段。**

`mem_core::compress::TAIL_OPS: &[TailOp]`，每项 `{ name, prompt }`，随投影下发成
`tails: [{ name, prompt, from_*, to_* }]`。加一个操作 = 表里加一项 + 调用方加一个
落地臂——两侧形状都不变，也没有可配置项（没有东西可配：操作就是代码）。调用方不认识
的名字**跳过并记一行日志**，不失败：store 的表可以先长，而在役的每个 guest 未必都升级
了，版本错位不该带走一轮 turn。

每一项自己声明**范围**。压缩的是「起点 = 调用方摘要已覆盖的点，终点 = 判词点名的
记录」；范围更窄的操作自己算。

**2. 压缩一次答两份：摘要，以及它本会选择的切点。**

摘要是必要的——那段记录变成不可直接读取，所以产不出来就是内容丢失。切点是**意见**，
记在摘要**旁边**，从不施加到摘要上：`CheckpointRow.suggested_ts` + `suggested_sub`
（`(0, 0)` = 没有）。

- 它**不移动覆盖点**。节点仍然关在判词说的位置，增量仍然在那里切。一个回溯进这段的
  建议会让记录静默掉出增量——正是 `coverage_sub` 防的那个错，只是高了一层。
- 它**要**对这段做校验：严格在该节点上一个指针之后，且不晚于本节点。等于本节点指针
  就是「机械切点重述一遍」，存成没有。越界是 400 并点名范围：后面每一趟都把这个值
  当成一段**存在过**的范围的起点，所以坏值不能存下来。
- 两段而不是一段：日志里的位置是一条**记录**（覆盖点那条教训）。

**3. 切点是**调用方**解析的序号，不是模型编的时间戳。**

调用方给它送出去的记录编序号（`[1]`、`[2]`…），模型答
`{"summary": …, "cut": N}`，由调用方——唯一造过这些消息的一方——把 `N` 映射回指针，
再由 store 校验。模型若直接回 `ts_ms`，等于陈述一个它看不见的事实；而在 store 里再写
一套编号逻辑，等于第二个真相源。

**4. 两个阶段，两套游标。**

尾操作共享**时机**（同一次判词、接在一次投影读取之后），但不共享**必要性**：压缩是必需
的——从不摘要的那段会无限增长——而回顾分析是可选的，它「没做」不是错误。所以它们推进
不同的游标：

- 压缩游标就是 checkpoint 链本身（摘要覆盖到哪）；
- 分析操作有**自己**的游标，范围从 `suggested_*` 到日志头，而不是从机械覆盖点起——那是
  模型看见的断点，不是字节预算挑的断点。

因为第二个游标是独立的，一趟永远不跑的回顾不花任何代价，跑晚了也仍然读对范围。第一阶段
落地的是第一个游标的第二份产物；第二个游标归下一份记录。

**5. 形状不对的回答仍然算摘要。**

提示词要一个 JSON 对象。模型若答了一段散文，它仍然产出了可用的摘要，于是调用方把整段当
摘要、没有切点。让一趟必要的操作唯一的产物因为格式滑了一下而丢掉，是错的取舍：格式是
优化，摘要是契约。

**6. 两个切点凑成训练数据。**

`(机械切点, 建议切点, 这段内容)` 是一个样本。现在没有任何东西导出它——存住就够让这个集合
存在，而在数据被收集之前写采样器，没有东西可采。

## 后果

- **再加两个操作不必动线上形状**，两个方向都是：这里加表项，那里加落地臂。操作仍欠的是
  自己的游标和自己的门。
- **压缩这一趟多付一个输出字段**，投影多一个键。反过来做（晚点再问模型一遍）要重读同一
  段，整整多一趟。
- **建议在有人读它之前是惰性的**：不进排序、不进检索、不建路径，它是节点上的一个标签。
- **开放：** 分析游标的落点（checkpoint 字段、按 member 的游标行，还是按操作的行）未定——
  它随回顾分析一起落地，那也是「回顾分析产出什么」不再只是假设的时候。ADR-0016 打开的
  计数/衰减问题，这里没有碰。
